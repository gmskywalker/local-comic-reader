# 本地漫画阅读器

把本地图片漫画整理成离线网页书架，并按需要导出为 CBZ 或带章节目录的 EPUB。

**Windows · 单文件工具 · 相对路径 · 不上传漫画 · 支持任意章节名与自定义顺序**

</div>

---

## 项目简介

这是一套面向 Windows 的本地漫画管理工具。它不提供漫画内容，也不连接漫画网站；所有扫描、整理、网页生成和格式导出都在本机完成。

| 文件 | 用途 |
| --- | --- |
| `漫画阅读器.html` | 本地书架、漫画目录和连续下拉阅读页面 |
| `漫画更新器.vbs` | 扫描漫画根目录，核验图片并重新生成网页 |
| `new/漫画整理器.vbs` | 合并分散章节、拆分总集、调整顺序、标题与封面 |
| `漫画导出器.vbs` | 导出分话 CBZ、整本 CBZ 或带可点击目录的 EPUB |

两个更新类工具和整理器均为单文件 VBS：PowerShell 主程序已压缩嵌入其中，双击时由 Windows Script Host 静默启动，因此不会留下黑色命令行窗口。关闭图形界面后，后台进程也会退出。

> [!IMPORTANT]
> 仓库和发布压缩包不包含任何漫画、封面、阅读记录或作者作品。请只处理你有权保存和阅读的内容。

## 下载

下载 [`release/local-comic-reader-windows.zip`](./release/local-comic-reader-windows.zip)，解压到任意漫画根目录即可。也可以克隆整个仓库；日常使用只需要四个运行文件。

推荐布局：

```text
我的漫画/
├─ 漫画阅读器.html
├─ 漫画更新器.vbs
├─ 漫画导出器.vbs
├─ 漫画 A/
│  ├─ cover.jpg
│  ├─ 第1话/
│  │  ├─ 0001.jpg
│  │  └─ 0002.jpg
│  └─ 特典/
│     ├─ 0001.jpg
│     └─ 0002.jpg
└─ new/
   ├─ 漫画整理器.vbs
   └─ 刚下载、尚未整理的漫画文件夹/
```

工具只使用自身所在位置和相对路径确定工作区。漫画根目录可以改名、换盘符或整体复制到另一台电脑。

## 30 秒生成网页书架

1. 把 `漫画阅读器.html`、`漫画更新器.vbs` 放在漫画根目录。
2. 双击 `漫画更新器.vbs`。
3. 只勾选需要进入书架的漫画；可选择更新后是否自动打开阅读器。
4. 完成后打开 `漫画阅读器.html`。

网页阅读器提供：

- 图片等宽、无缝的纵向连续阅读；
- 阅读页置顶工具栏，只保留“当前话 / 总话数”和必要按钮；
- 多档缩放，只影响阅读页，不改变书架和目录页；
- 独立的背景颜色、文字颜色按钮，含预设色、颜色选择器和自定义收藏槽；
- 漫画、章节和图片位置的本地进度记录；
- 适配常见桌面与手机浏览器宽度。

每部漫画的网页入口会生成在该漫画根目录中，不会在每话文件夹里散落 HTML。生成的网页使用相对路径引用图片。

## 支持的漫画结构

### 多章节漫画

```text
漫画名/
├─ cover.jpg
├─ 第1话/
├─ 第4.5话/
├─ 特典/
└─ after/
```

章节文件夹不要求必须叫“第 X 话”。`特典`、`番外篇`、`after`、英文名或其他任意名称都可作为章节。

- 有整理器元数据时，严格采用你确定的顺序和显示标题；兼容早期整理器生成的元数据。
- 没有元数据时，按文件夹名称自然排序。
- `4.5`、`8.5` 等小数章节按数值位置排序。
- `1.01话 特典` 或纯文字 `特典` 如果需要放到最后，请使用整理器上移、下移；显示编号不决定最终顺序。

### 根目录单行本

```text
漫画名/
├─ 0001.jpg
├─ 0002.jpg
└─ 0003.jpg
```

漫画根目录直接包含正文图片时，会自动作为一话处理，不必额外创建“第1话”文件夹。

### 复合命名或总集

```text
P01_001.jpg
P01_002.jpg
P02_001.jpg
P02_002.jpg
```

整理器会尝试识别“章节组 + 页码”模式并自动生成章节。无法识别固定模式时，按完整文件名自然排序。输出时复制图片到新漫画文件夹，并统一重命名为 `0001`、`0002`……，不会改动原文件。

支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.bmp`、`.avif`。`cover.jpg`、`cover.png` 等会优先作为封面；没有封面文件时可使用第一张正文图。

## 漫画整理器

把 `漫画整理器.vbs` 放在下载区（通常为 `new`）并双击运行。输出会写入新的“整理完成”目录，原始下载文件保持不变。

整理器可以：

- 把多个分散文件夹合并成一部漫画；
- 把多个来源合并为同一话；
- 按图片起止范围把总集拆成多话；
- 为每话分别设置显示编号和章节标题；
- 上移、下移章节，确定真实阅读顺序；
- 在来源表格最后一列勾选封面来源；
- 保存和重新载入整理方案；
- 只导出总集中的一部分，列出未使用图片后由用户二次确认。

“按当前顺序编号”会从选中行的下一行继续：选中第3话后从4开始，选中第4.5话后从5开始。没有传统数字编号的 `特典话` 也可以手动命名和放置。

## 图片顺序与缺页检查

| 文件名情况 | 排序与核验 |
| --- | --- |
| `0001.jpg`、`0002.jpg`…… | 按数字排序，并检查起始编号、断号和重复号 |
| `P01_001.jpg`、`P01_002.jpg`…… | 识别章节组和页码，在组内检查重复及明显断号 |
| 无法识别的名称 | 按名称自然排序；因没有可靠页码，只提示无法严格判断缺页 |

自然排序会把 `2.jpg` 放在 `10.jpg` 前。遇到混用多套命名规则或无法确认顺序时，工具会要求确认，不会静默丢弃已找到的图片。

## JSON 元数据的作用

整理器输出的 `元数据.json` 用于记录：

- 章节的严格阅读顺序；
- 每话的显示编号和独立章节标题；
- 封面来源；
- 整理器版本和必要的结构信息。

没有 JSON 时，更新器和导出器仍可工作，只是改用名称自然排序。JSON 不是漫画内容；导出 CBZ 或 EPUB 时只读取它，不会把源 JSON 和网页文件复制进电子书。

## CBZ / EPUB 导出

把 `漫画导出器.vbs` 放在漫画根目录并双击运行。默认输出目录是同级的 `CBZ导出`，也可以自行选择其他目录。

### 每话一个 CBZ

每部漫画输出为一个文件夹，每话是一个单独 CBZ：

```text
CBZ导出/
└─ 漫画名/
   ├─ 001 - 第1话.cbz
   ├─ 002 - 第2话.cbz
   └─ 003 - 特典.cbz
```

适合 Mihon 等专门漫画阅读器。CBZ 内只有按 `000001`、`000002`……重命名的图片，不包含源 JSON、HTML 或其他杂项。

### 整部漫画一个 CBZ

所有章节图片合并进一个 CBZ，手机书架只显示一本，但 CBZ 标准本身没有可靠的跨阅读器章节目录。适合只需要顺序阅读、不要求章节导航的场景。

### 整部漫画一个 EPUB

每部漫画输出一个 EPUB，并生成标准 EPUB 3 导航目录：

- 手机书架一部漫画只显示一本；
- 目录中的每个章节可以点击；
- 每话正文图片按确定顺序纵向排列；
- 封面、作者和简介会在可用时写入电子书元数据；
- 同时生成 EPUB 3 导航和兼容旧阅读器的 NCX 目录。

EPUB 阅读时究竟采用水平分页、垂直翻页还是连续滚动，由手机阅读 App 决定。ReadEra 适合“一本书 + 可点击目录”；如果必须获得网页漫画式无缝长条阅读，推荐使用下面的 Mihon 方案。

## 手机上阅读

### ReadEra：一本 EPUB 对应书架一本书

把导出的 `.epub` 文件复制到手机并让 ReadEra 扫描。打开后可通过目录按钮跳转章节。ReadEra 支持水平或垂直翻页，但不保证所有 EPUB 都以网页式无缝长条显示。

### Mihon：一部漫画、多个章节、无缝长条

Mihon 更适合图片漫画。把“每话一个 CBZ”生成的整个漫画文件夹复制到手机：

```text
Mihon/local/
├─ 漫画 A/
│  ├─ 001 - 第1话.cbz
│  └─ 002 - 第2话.cbz
└─ 漫画 B/
   ├─ 001 - 第1话.cbz
   └─ 002 - 特典.cbz
```

然后在 Mihon 中进入“浏览 → 图源 → 本地来源”并刷新。书架会按漫画文件夹显示，每部漫画内列出各话。打开章节后点击屏幕中央 → 齿轮 →“本系列阅读模式”，选择 `长条模式（Long strip）` 即可从上到下无缝阅读。

- [Mihon 官方下载](https://mihon.app/download/)
- [Mihon 本地漫画说明](https://mihon.app/docs/guides/local-source/)
- [Mihon 阅读模式说明](https://mihon.app/docs/guides/reader-settings)

## VBS 和 EXE 有什么区别？

VBS 是由 Windows Script Host 执行的脚本；EXE 是 Windows 可执行程序，可能是原生编译程序，也可能只是其他脚本和运行环境的封装。

本项目使用 VBS，是为了在不附带额外运行库的情况下实现单文件、无黑框、相对路径和便于检查源码。EXE 更方便设置图标、版本信息和数字签名，但未签名 EXE 同样可能触发 SmartScreen，功能也不会天然更强。

## 从源码重新打包

完整 PowerShell 源码位于 `source/`：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\source\build-single-file-tools.ps1 `
  -OutputDirectory .\.tmp
```

生成文件：

- `.tmp/漫画更新器.vbs`
- `.tmp/漫画整理器.vbs`
- `.tmp/漫画导出器.vbs`

将更新器和导出器放在漫画根目录；整理器可以放在漫画根目录下任意下载区，例如 `new/`。

## 常见问题

<details>
<summary><strong>双击 VBS 后为什么没有黑色命令行窗口？</strong></summary>

这是正常设计。VBS 隐藏 PowerShell 控制台，只显示图形界面；关闭图形界面后后台进程随之退出。

</details>

<details>
<summary><strong>Windows 提示脚本来自未知发布者怎么办？</strong></summary>

这些工具没有商业代码签名。可以先阅读 `source/` 中的完整 PowerShell 源码；VBS 只是把相应源码压缩嵌入后静默运行。请只从本仓库下载。

</details>

<details>
<summary><strong>为什么漫画没有出现在更新器或导出器列表？</strong></summary>

确认漫画目录中至少有一个受支持格式的图片文件。图片既可以位于章节子文件夹，也可以直接位于漫画根目录。空目录或只有 JSON、HTML 而没有图片的目录不会成为候选漫画。

</details>

<details>
<summary><strong>为什么把分话 CBZ 导入 ReadEra 后变成很多本书？</strong></summary>

ReadEra 把每个 CBZ 当成一本独立文档。需要“一本书 + 可点击章节目录”时导出 EPUB；需要“一部漫画 + 章节列表 + 无缝长条”时，把分话 CBZ 文件夹放入 Mihon 的本地来源目录。

</details>

## 已知边界

- 完全没有数字规律的文件名只能自然排序，无法可靠证明是否缺页。
- 同一文件夹混用多套命名规则时，建议先用整理器预览并确认。
- 同名但扩展名不同的图片可能造成页码重复歧义。
- 超长路径可能受 Windows 或解压软件限制，建议不要把漫画根目录嵌套得过深。
- HTML 阅读器适合本机离线阅读；跨设备同步进度、网络书库和多人共享不在本项目范围内。
